# raymi.xyz

Raymond Csirák's personal portfolio, built with Next.js and TypeScript.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Cloudflare Workers

```bash
npm run preview
npm run deploy
```
