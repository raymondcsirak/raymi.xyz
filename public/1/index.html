03:00 The quiet hours

How I work

A good night shift is uneventful. That takes some planning in daylight.

  1. 03:07

    Automation over heroics

    If a fix has to happen twice, it becomes a pipeline, a Puppet or Ansible run, or a small tool in Python. Nobody should depend on one person remembering the steps.

  2. 03:24

    Everything lives in Git

    Cluster configuration and deployments are described as code and delivered through Argo CD, so every change is reviewed and can be rolled back.

  3. 03:41

    Recovery plans get tested

    A backup counts once it has been restored. Disaster recovery is designed and written down before it is needed.

  4. 03:58

    Monitoring that means something

    An alert should wake a person only when a person has to act. Everything else belongs on a dashboard for the morning.
