Thank you for choosing Raymi: Site Reliability. Please read this booklet before you start, and keep it for reference.

Raymond Csirák, called Raymi, is a Senior Site Reliability Engineer at GoDaddy. He builds and runs private cloud infrastructure, including large-scale OpenStack, and writes the automation and Python tooling around it.
